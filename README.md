# Site & Soil Field Log

A phone app for recording a BC SPM v3 site and soil evaluation in the field, and exporting it to Excel, Word or PDF.

**Open the app:** https://westcoastseptic.github.io/site-soil-field-log/

On iPhone, open the link in Safari, tap Share, then Add to Home Screen. On Android, open it in Chrome, tap the ⋮ menu, then Install app.

All site data stays on the user's own phone. Nothing is sent to this website or to Beaty Hydro Corporation.

## Files

- `index.html`: the app.
- `sw.js`: lets the app open offline.
- `manifest.webmanifest` and `icons/`: the home-screen name and water-drop icon.

These files are generated from the master copy kept in the Beaty Hydro project files. Edit the master and rebuild rather than editing here.
